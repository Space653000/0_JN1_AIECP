# AIECP 使用手冊

這份手冊是寫給實際使用 AIECP（AI Engineering Control Plane）的人看的，語氣盡量口語，不堆條列。如果你想知道「這個專案技術上是怎麼做的」，請看 [`.ai/BLUEPRINT.md`](../.ai/BLUEPRINT.md)；這裡只講「我該怎麼用它」。

## 安裝與啟動

AIECP 目前只支援 Windows。安裝檔是單一個 `AI-Engineering-Control-Plane-Setup-<版本>.exe`，不管你的電腦是一般的 x64 還是 ARM64（例如 Windows on Arm 筆電），下載同一個安裝檔就好，AIECP 會在安裝時自動偵測你的處理器架構，不需要你自己選 x64 或 ARM64 版本。如果你想要指定架構的安裝檔（例如公司 IT 要求），Release 頁面也有分開的 x64 和 ARM64 版本可以選，但一般人不需要用到它們。

安裝程式不是一鍵完成的：它會先給你選安裝路徑，你可以直接按下一步用預設路徑。因為 AIECP 目前還沒有付費的程式碼簽章憑證，Windows SmartScreen 可能會跳出「Windows 已保護您的電腦」的警告。這是正常現象，不代表程式有問題：點「其他資訊」再點「仍要執行」就可以繼續安裝。之後每次更新，AIECP 都會用 SHA-256 驗證下載的檔案，確保下載的內容沒有被竄改。

安裝完成後第一次開啟，AIECP 不會馬上要你做很多設定，它會先自動偵測你電腦上有哪些工具（Git、PowerShell、Python、Node、GitHub CLI、Ollama 等），這個過程不需要你做任何事。

## 選擇 Workspace

AIECP 唯一需要你自己選的東西，就是「Workspace」——也就是它可以檢視的那一個資料夾。這是刻意設計成這樣的：AIECP 不會自己去猜你想用哪個專案，也不會掃描你整台電腦的檔案，一定要你自己點「選擇資料夾」明確指定。

選好之後，AIECP 會在那個資料夾底下（只有第一層）自動找出裡面的 Git 儲存庫，並偵測本機有哪些工具可以用。你隨時可以換一個 Workspace，或是移除目前的綁定——移除綁定只是讓 AIECP 忘記這個資料夾的位置，並不會刪除或修改資料夾裡任何一個檔案。

## 供應商設定

AIECP 不強迫你使用任何特定的 AI 供應商。預設情況下，你可以直接用官方 ChatGPT 網頁版——這一頁完全是你平常用的瀏覽器分頁、你自己的帳號，AIECP 不會注入、擷取或修改這個網頁的任何內容，也不需要你輸入任何 API 金鑰。

如果你想用更進階的功能（例如自動化的 Harness 迴圈），可以額外登記其他供應商：

- **官方登入（Codex OFFICIAL）**：這是 OpenAI 官方的 Codex，登入時 AIECP 會開一個獨立的登入視窗，只給這個 Worker 專用、彼此隔離的設定資料夾，跟你電腦上其他地方安裝的 Codex 互不影響。登入一次之後，AIECP 會記得你已經登入，之後不需要重複登入。
- **PEGA**：這是另一個以 Codex 相容介面提供服務的供應商，網址是 `https://aiapi.t-cyber.com/v1`。要用 PEGA，你需要輸入明確的模型名稱（例如 `Pega-Coding`）和一組金鑰。金鑰會由 Windows 的安全儲存機制加密保存，AIECP 的畫面上任何地方都不會把它印出來。
- **Ollama**：如果你電腦上已經裝了 Ollama 並且有下載模型，AIECP 可以直接讀取你已安裝的模型清單讓你選，不需要額外設定網址或金鑰。

## 每個 Agent 的模型與推理強度，還有「打招呼」

在「AI Agent」那一區，每個 Agent（Claude Code、Codex OFFICIAL、Codex PEGA、Ollama 等）卡片下面都有一個可以展開的「模型與強度」小區塊。你可以在這裡指定要用哪個模型，以及推理強度——不同工具支援的強度等級不太一樣（Codex 系列是 `minimal` 到 `xhigh`，Claude Code 是 `low` 到 `max`，Ollama 是思考模式的「低、中、高」），如果某個工具本來就沒有強度這個概念（例如 Gemini、OpenCode），畫面上就會直接寫「不適用」，不會硬湊一個假的選項給你。

設定好之後，你可以按「打招呼」，AIECP 會請那個 Agent 用固定的一句問候回你話，藉此確認設定真的生效了。這個按鈕只會送出固定的問候語，不能拿來打字問別的問題——它的用途純粹是「確認這個 Agent 真的通了」，不是聊天室。如果某個 Agent 需要連網路或會用到你的帳號額度，畫面會先提醒你，按下按鈕本身就代表你同意這一次呼叫。打完招呼後，畫面會顯示：實際用了哪個模型、花了多久、成功或失敗，如果失敗會告訴你真正的原因（例如額度用完、還沒登入），不會只顯示「失敗」兩個字讓你猜。

官方 ChatGPT 網頁版是唯一的例外：因為它是你在自己瀏覽器裡操作的官方網站，AIECP 不會、也不可能替你在那邊選模型或強度，所以它的卡片只會說明這件事，不會出現設定欄位或打招呼按鈕。

## Harness 各區塊在說什麼

如果你打開工程模式的「Harness」頁，會看到不少卡片，這裡簡單說明每一區大概在講什麼：

「執行期訊號」是整個系統目前的健康狀態總覽——核心控制平面、AI 迴圈、GitHub/CI、治理、多儲存庫、遠端連線，各自是不是正常。這裡有個很重要的原則：如果 AIECP 沒辦法實際驗證某個狀態，它會誠實地顯示「未知」，而不是隨便猜一個綠色的「沒問題」出來騙你。

「V3.0 Multi-Worker 就緒度」是在檢查兩個 Codex Worker（OFFICIAL 跟 PEGA）是不是各自獨立、互不干擾。如果你看到某個 Worker 顯示「DEGRADED」，但旁邊多了一行「這是閒置時的正常狀態」，代表它只是還沒被核准使用網路而已——AIECP 只有在真的要派工給它的時候，才會跳出來請你核准，平常閒置時顯示這個狀態是正常的，不代表壞掉了。

「Worker 執行期」列出目前每個 Worker 正在做什麼、用哪個模型、在哪個資料夾工作、驗證進行到哪一步。「Mission 佇列」跟「核准佇列」是你交辦的工作，以及正在等你點頭的項目。「即時事件串流」則是所有動作的完整記錄，方便你回頭查發生過什麼事。

## 常見錯誤和怎麼處理

**`spawn codex ENOENT`**：這代表 AIECP 找不到可以直接執行的 Codex 執行檔。如果你是透過官方 Codex 桌面應用程式安裝的，AIECP 現在會自動去它的安裝資料夾裡找到正確的執行檔，不需要你自己調整系統的 PATH 環境變數。如果你是用別的方式安裝 Codex（例如透過 npm 安裝的指令列版本），請確認那個安裝方式產生的執行檔本身在 PATH 裡找得到。

**`requires authentication`／尚未登入**：代表這個 Worker 還沒完成登入，或是登入的憑證過期了。到「AI Agent」區塊找到對應的 Worker 卡片，重新走一次登入流程即可。

**額度用完**：如果打招呼或實際執行任務時看到類似「已達使用上限，請稍後再試」的訊息，代表你的帳號在這個供應商那邊的用量額度用完了，這不是 AIECP 的問題，訊息裡通常會告訴你大概什麼時候恢復，請照著等待或聯絡供應商。

**Windows 檔案被鎖**：Windows 有時候會因為防毒軟體正在掃描，或是另一個程式還占用著某個設定檔，導致 AIECP 寫入檔案時暫時失敗。AIECP 本身已經會自動重試幾次；如果重試後還是失敗，通常過一下子再試一次就會好，不需要重開機。

## 備份與還原

在設定裡的「本機資料控制」區塊，你可以匯出備份——AIECP 會把它自己管理的狀態、執行記錄和證據打包起來，每個檔案都附上 SHA-256 雜湊值方便驗證完整性，但**絕對不會把你的供應商金鑰包含在備份裡**。還原的時候，AIECP 會先把要還原的內容驗證過、放到暫存位置，並且保留一份還原前的備份，確認沒問題後才會真的套用並重新啟動。不管是匯出還是還原，都只影響 AIECP 自己的狀態，你的 Workspace 專案檔案完全不會被動到。

## 緊急停止

如果你在 Harness 頁面看到紅色的「全部停止」按鈕，按下去會立刻取消所有正在進行中的 Mission。這是給你在覺得事情不對勁、想馬上喊停時用的；按下去之後不會有任何未經你核准的動作繼續執行。
