## 0. 背景與規則

擁有者在 0019 的「模型」欄位手打了 `SONNET5`（應為 `claude-sonnet-5`），Claude 拒絕並回報原因，功能正確，但擁有者指出：**確切型號名稱會隨官方更新而改變，不該要求手記。**

已查證：`claude --help` 沒有「列出全部模型」的指令，但支援官方維護的**別名**：`sonnet`、`opus`、`fable`（對應目前最新的 Sonnet／Opus／Fable 世代，官方自己保持更新，不會過期作廢）。PEGA、Codex OFFICIAL 沒有可靠的自動偵測方式（PEGA 的 `/v1/models` 查不到 Codex 用的模型名；Codex 官方模型庫沒有公開清單指令），**這兩個不在本單範圍**，維持現在的自由輸入＋錯誤原因原樣顯示（已證明可用：擁有者打錯 `SONNET5` 時，畫面正確顯示官方回的原因）。

**只加不改**：Claude Code 現有的自由輸入不移除，仍可手動輸入完整型號名稱；未設定時行為不變；不改其他 Agent。

## 1. 要做的事

`ui/app.js` 的 Claude Code 模型欄位（`agentPanelHtml`，`id==='claude-code'`）比照 Ollama 的做法，改成下拉選單＋允許自訂：

- 選項固定為：`使用預設`、`sonnet`、`opus`、`fable`，另外加一個「自訂…」選項，選了才顯示文字輸入框（沿用現有 input，maxlength 120，格式檢查不變）。
- 若目前設定值不在上述別名清單中（例如擁有者之前存了完整型號），下拉選單顯示「自訂」並把原值帶進文字框，不遺失既有設定。
- 這四個別名的清單放成一個具名常數（例如 `electron/lib/agent-settings.cjs` 的 `CLAUDE_MODEL_ALIASES`），並在旁邊註解註明「官方維護的別名，不是本專案凍結的型號名稱」，方便日後官方新增別名時只改一處。
- 說明文字（i18n）：「sonnet／opus／fable 是官方別名，會自動對應到最新版本；要指定確切型號才選『自訂』。」

## 2. 測試與破壞檢查

- 測試：別名清單存在且為具名常數；下拉選單渲染四個固定選項＋自訂；已存在的自訂值被正確識別為「自訂」並保留；選別名時傳給 `claude` 的旗標與現在完全相同格式（`--model <值>`，值就是別名字串，不做轉換）；未選任何值（使用預設）時行為與現在相同。
- 破壞紀錄至少 2 筆（例如把別名清單清空、把「自訂」偵測邏輯改壞）。
- 不改動 PEGA、Codex OFFICIAL、Ollama、Gemini、OpenCode 的既有測試斷言。

## 回報

### 做了什麼
`electron/lib/agent-settings.cjs` 新增具名常數 `CLAUDE_MODEL_ALIASES = ['sonnet','opus','fable']`（有註解說明是官方別名，不是本專案凍結的型號名稱）。`electron/main.cjs` 的 `getAgentSettingsView` 只給 `claude-code` 這一項回傳 `knownModels`。`ui/app.js` 的 `agentPanelHtml` 新增一個通用的「已知清單＋自訂」欄位型態（`knownModels`），目前只有 Claude Code 用到；選單有四個固定選項＋「自訂…」，選自訂才顯示文字輸入框；如果目前設定值不在別名清單裡（例如你之前存過完整型號），下拉會自動顯示「自訂」並把原值帶進文字框，不會遺失。選好別名或輸入完整型號後，傳給 `claude` 的仍是原本的 `--model <值>` 格式，沒有做任何轉換。沒有設定時（使用預設）行為與之前完全相同。

### PEGA、Codex OFFICIAL 為何不在本單範圍（給擁有者看）
PEGA 的 `/v1/models` 查不到 Codex 用的模型名稱，Codex 官方也沒有公開的「列出全部模型」指令可以查，所以這兩個沒有辦法像 Claude 一樣做成清單，維持現在的自由輸入框——你打錯字時，畫面會照樣顯示官方回的錯誤原因（已驗證過：之前你打 `SONNET5` 時就是這樣）。

### 測試與破壞紀錄
新增 `tests/claude-model-alias-dropdown.test.cjs`，8 個測試：別名清單是具名常數且格式不變、下拉選單渲染四個固定選項＋自訂、既有自訂值正確顯示為自訂並保留、選自訂會出現空的文字框且不影響其他欄位、輸入的值正確送出、選別名正確送出、不選任何值行為不變、Ollama／PEGA／Codex OFFICIAL 完全沒被動到、透過真的主程序確認只有 `claude-code` 拿得到 `knownModels`。破壞紀錄 4 筆（清空別名清單、關閉自訂偵測、關閉選單切換邏輯、移除主程序的 `knownModels` 欄位），全部 DETECTED。矩陣新增 W0021，PEGA／Codex OFFICIAL／Ollama／Gemini／OpenCode 的既有測試斷言沒有改動。
